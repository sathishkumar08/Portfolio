# Portfolio

Personal portfolio of Sathishkumar Durai — DevOps, SRE and Platform Engineering.

Live: https://sathishkumar08.github.io/Portfolio/

Plain HTML, CSS and JavaScript — no build step. Every push to `main` runs a link check and deploys to GitHub Pages via GitHub Actions ([deploy.yml](.github/workflows/deploy.yml)).

## Run locally

```sh
python3 -m http.server 8080
```

Then open http://127.0.0.1:8080/.
